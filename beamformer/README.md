# Beamforming Simulation Project

This project simulates a linear hydrophone array receiving a chirp signal from a far-field source.
It demonstrates basic delay-and-sum beamforming principles using Python.

## Features
- Chirp signal generation
- Synthetic array signal delays based on DOA
- Visualization of array signals

## Run
Open the `beamforming_simulation.ipynb` notebook and run all cells.
