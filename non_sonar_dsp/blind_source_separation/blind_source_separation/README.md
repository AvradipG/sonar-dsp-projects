# Blind Source Separation (ICA/PCA) Project

This project demonstrates how to separate mixed signals (e.g., overlapping speech or sine waves) using:
- Independent Component Analysis (ICA)
- Principal Component Analysis (PCA)

## 🎯 Goals
- Understand how ICA separates statistically independent sources
- Use PCA for decorrelation and dimensionality reduction
- Simulate the 'Cocktail Party Problem'
- Visualize mixed vs separated signals

## 📚 Concepts Covered
- Mixing matrix and signal mixtures
- Statistical independence vs correlation
- FastICA algorithm
- PCA using SVD or covariance matrix
- Signal reconstruction

## 🔧 Tools Used
- Scikit-learn (FastICA, PCA)
- NumPy
- Matplotlib
