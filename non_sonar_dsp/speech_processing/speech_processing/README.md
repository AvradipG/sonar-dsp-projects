# Speech Processing Project

This project introduces basic techniques in speech signal processing, including:
- Voice Activity Detection (VAD)
- Denoising and feature extraction
- MFCC computation
- (Optional) Speech classification using machine learning

## 🎯 Goals
- Load and visualize speech signals
- Apply basic denoising
- Extract MFCCs for feature representation
- Apply simple classifiers (optional)

## 📚 Concepts Covered
- Time-domain and frequency-domain view of speech
- MFCC (Mel-Frequency Cepstral Coefficients)
- Voice Activity Detection (VAD)
- Feature extraction pipeline
- Speech classification (optional)

## 🔧 Tools Used
- Librosa
- NumPy
- Matplotlib
- Scikit-learn (optional)
