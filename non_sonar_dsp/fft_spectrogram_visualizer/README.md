# Time-Frequency Visualizer (FFT + Gabor Transform)

This project demonstrates how to analyze time-varying frequency content using FFT and Gabor Transform (Gaussian-windowed STFT).

## Goals
- Understand FFT vs STFT vs Gabor Transform
- Use spectrograms to visualize how frequency content changes over time
- Adjust Gaussian window width to see time-frequency resolution tradeoffs

## Concepts
- Frequency domain analysis (FFT)
- Time-frequency resolution
- Windowing and overlap
- Gabor Transform: a Gaussian-windowed STFT

## Tools Used
- Python
- NumPy
- SciPy
- Matplotlib
- Streamlit (for GUI)
