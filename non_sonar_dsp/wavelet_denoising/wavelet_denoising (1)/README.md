# Wavelet Denoising Project

This project demonstrates how to use Discrete Wavelet Transform (DWT) for denoising signals and compares the results with traditional low-pass filtering.

## 🎯 Goals
- Understand how wavelet denoising works
- Apply thresholding techniques (soft, hard)
- Compare wavelet denoising vs FIR/IIR filters
- Visualize time-domain reconstruction and error

## 📚 Concepts Covered
- Discrete Wavelet Transform (DWT)
- Signal sparsity in wavelet domain
- Thresholding: soft vs hard
- Inverse DWT for reconstruction
- Error and SNR comparison

## 🔧 Tools Used
- PyWavelets (`pywt`)
- NumPy
- Matplotlib
- SciPy
