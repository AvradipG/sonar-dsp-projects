# Digital Filtering Playground

This project demonstrates how to design and apply FIR and IIR filters to noisy signals.

## 🎯 Goals
- Understand the difference between FIR and IIR filters
- Design filters using standard methods (Butterworth, Chebyshev, windowed FIR)
- Apply filters to synthetic or real audio/seismic signals
- Visualize frequency response and filtering effects

## 📚 Concepts Covered
- Impulse response
- Frequency response
- Filter order and stability
- Spectral leakage and aliasing
- Real-time vs offline filtering

## 🔧 Tools Used
- Python (NumPy, SciPy, Matplotlib)
- Jupyter Notebook
- `scipy.signal` for filter design
