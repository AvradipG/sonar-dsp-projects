## 📖 Table of Contents

| Notebook                  | Description                                                      |
|---------------------------|------------------------------------------------------------------|
| fft_utils.ipynb           | Fast Fourier Transform (FFT/IFFT), frequency analysis, 1D & 2D   |
| filter_utils.ipynb        | Moving average, FIR, and IIR filters (with demos)                |
| matched_filter_utils.ipynb| Matched filter for pulse/echo detection in noisy data            |
| beamforming_utils.ipynb   | Delay-and-sum beamforming for array signal processing            |
| spectrogram_utils.ipynb   | Time-frequency analysis with spectrograms                        |
| signal_generation_utils.ipynb | Generate chirps, pulses, multisine, and white noise       |
| convolution_utils.ipynb   | Convolution, autocorrelation, and cross-correlation utilities    |
| correlation_utils.ipynb   | Autocorrelation and cross-correlation with demos                 |
| plotting_utils.ipynb      | Standardized plots: time series, spectrum, array, spectrogram    |
| window_utils.ipynb        | Windowing functions (Hann, Hamming, Blackman, etc.)              |
| roc_utils.ipynb           | ROC curve & AUC for detection/classification (sklearn & numpy)   |
| dataio_utils.ipynb        | Read/write WAV, CSV, NPY files for signal data                   |
| envelope_utils.ipynb      | Envelope detection (Hilbert transform and abs)                   |
| peak_utils.ipynb          | Simple and robust (scipy) peak detection                         |
| array_sim_utils.ipynb     | Simulate signals for a sensor/hydrophone array                   |
| full_sonar_pipeline.ipynb | End-to-end demo: generate, filter, envelope, detect, analyze     |

## 🚀 Quick Start

1. **Clone the repo**:
    ```bash
    git clone https://github.com/YOUR_USERNAME/sonar-dsp-utils.git
    ```
2. **(Optional) Create a virtual environment and install dependencies**:
    ```bash
    pip install numpy scipy matplotlib scikit-learn
    ```
3. **Open any notebook in Jupyter Lab or Jupyter Notebook**.
